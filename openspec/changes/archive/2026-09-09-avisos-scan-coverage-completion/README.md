# avisos-scan-coverage-completion

Cierra los pendientes finales del módulo de avisos: (1) endpoint client-facing para que cada cliente vea SU cobertura y pueda solicitar rewind/activar histórico; (2) exportador XLSX del audit log; (3) readiness check que avisa al admin cuando los triggers de partición se acercan; (4) política de retención del audit log configurable; (5) endpoint de métricas históricas de cobertura (evolución diaria).
